# Abartılı Yavaş Hesap Makinesi

## Giriş

Bu proje, modern dünyanın en büyük sorunlarından birini çözmek üzere tasarlanmıştır: **Acelecilik.**

Artık hesap yaparken beklemek zorunda değilsiniz... Hayır, tam tersi. Bu hesap makinesi, size beklemenin erdemini öğretir.

### Özellikler

- Gerçekten çalışır (test edildi, 2+2 = 4 çıktı, ama 8 saniye sonra)
- Sabır geliştirir
- Kahve içme fırsatı sunar
- Evrenin en yavaş algoritması
- Hiçbir optimizasyon içermez, bilerek

### Kullanım

```bash
python hesap_makinesi.py
```

Sonra bir işlem girin. Mesela `42*13`. Sonucu almak için roman okuyabilirsiniz.

### Neden?

Çünkü hızlı hesap makineleri var. Ama yavaş olanı yoktu. Artık var.

Bu proje, "neden olmasın?" felsefesinin en saf halidir.

### Uyarı

Bu kodu üretimde kullanmayın. Gerçekten. Çok yavaş.
